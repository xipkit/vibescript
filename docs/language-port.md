# The port from Go

This implementation began in September 2026 as a Rust core experiment: an embeddable subset of Vibescript compiled to bytecode, with bounded work, tracked memory, recursion limits, deadlines and cooperative cancellation, benchmarked against Go Vibescript v0.70.0 with and without Go 1.27.1's SIMD experiment. Its goal then became the whole language, with Go v0.70.0 at commit `5cba216c33bea8890787d64efb2ab926a761fb1b` as the compatibility reference. Performance work waited for language coverage, and the accounting and cancellation contracts held throughout.

Go's results were the target. Shared fixtures ran through both implementations, with independently computed expectations where possible; the 203 website programs and the upstream examples ran unchanged; every `Script.Call` and compile made by Go's test suite was recorded and replayed; and the CLI, the language server and the first parse error on mutated corpus programs were compared side by side. Where Go contradicted Vibescript's documented value semantics or behaved inconsistently, the port followed the documentation; [the differences](compatibility.md) list those decisions. The accounting model deliberately charges differently from Go's.

On 2026-09-23 the port was complete. Of the 16,717 replayable calls from Go's test suite, 13,984 returned the same value and 2,666 raised the same error with the same message; the rest were host-side renderings, nondeterministic Go results, NaN sign bits scripts cannot observe, selected differences and two host errors of a different kind. Of 2,576 compile-only sources, 2,313 agreed; the others contain top-level statements, which this implementation compiles into `__main__`. All 203 website programs matched. The full gate passed on macOS arm64 and Linux x86_64, and the test suite on wasm32-wasip1.

On 2026-09-24 the Rust implementation became the reference, and the language moved to the static types and canonical surface of [ADR-007](adr/007-static-types.md) and [ADR-008](adr/008-canonical-surface-for-ai-authors.md); see the [language guide](language.md). The [golden corpora](../tests/golden/README.md) record its behavior on every corpus once validated against Go, so validation needs no Go toolchain, and the Go comparison tools were removed. The Go implementation is deprecated and keeps the earlier, dynamically typed language. The original plan, the full port log and the comparison tools remain in the repository history.
