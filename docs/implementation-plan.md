# Rust core experiment

> The original plan for this repository, kept as history. It was superseded by the [language completion plan](language-port.md), and since 2026-09-24 this implementation is the reference; see the [language guide](language.md).

Build an embeddable Rust implementation of a useful Vibescript subset, then compare equivalent compiled calls against Go v0.70.0 with and without Go 1.27.1 SIMD. Keep the Go checkout unchanged.

The first core includes named positional functions, top-level statements, integers and floats, booleans and nil, byte strings and symbols, arrays and insertion-ordered hashes, assignment, indexing, arithmetic, comparisons, conditionals, while loops, return/break/next, selected string and collection methods, JSON parsing/stringification, and synchronous host functions. Unsupported language features must produce errors, not silently change behavior. Integer overflow reports an error until arbitrary precision is implemented.

Compile to bytecode with local slots and an explicit frame stack. Shared values preserve collection value semantics without cycles; array storage can be reused when no aliases exist. Bound compilation separately by source size and syntax depth. Each execution has a latched step budget, tracked runtime allocation budget, frame limit, monotonic deadline, and cooperative cancellation token. Builtins charge work and poll cancellation between bounded chunks. Track live capacity, temporary builders, frame/operand storage, imported arguments, and outputs. Compiled code and caller-owned storage that a call does not retain are outside the execution budget. Imported immutable strings share backing storage and charge its full capacity independently to each execution. This allocation model is intentionally different from Go's reachable-graph estimator and is not an RSS limit.

Provide a synchronous embedding API and CLI. An optional Tokio adapter uses bounded blocking workers, cancellation on dropped call futures, and keeps the permit until execution exits. Async host callbacks and native script suspension are future work.

Validate semantics with shared fixtures run by both implementations, test quota/cancellation boundaries and reclamation, compare portable and SIMD Rust scanners, and run formatting, Clippy, debug/release tests, and CLI smoke checks. Benchmark precompiled calls with identical data, accounting enabled and disabled, checksummed outputs, repeated alternating samples, per-call allocation measurements, and separate process memory measurements. Publish the raw data, environment, reproducible commands, and limitations alongside the comparison report. Do not infer a general Rust speedup from a smaller implementation.
