# Upstream Vibescript examples

These ten complete files are copied unchanged from Go Vibescript v0.70.0 under its MIT license. `sources.json` pins the repository, commit, paths, and SHA-256 hashes. `cases.json` selects existing named functions and supplies independently computed expected results. Both the Rust test suite and the Go/Rust comparison harness execute them.

The selected files exercise the implemented core: calls, arithmetic, conditionals, recursion, while/until loops, loop control, collection updates, and byte strings. Examples needing classes, blocks, ranges/for loops, modules, typing, host capabilities, and the wider standard library remain outside this prototype. Passing these cases does not establish full language compatibility.
