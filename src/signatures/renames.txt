# Removed spellings and what replaces them (ADR-008).
#
# The signature table lists only canonical names. Every other spelling the
# runtime still accepts is listed here, and the migration rewrites each call
# with its entry. Lines have the form
#
#   receiver: pattern => replacement
#
# The receiver is a class from builtins.vibe (`T` for every type), `global`
# for a global function, a namespace such as `Time`, `type` for a type name
# in annotations, or `*` for a rule that applies to every name, whose `$name`
# stands for that name. In a pattern, `$x` is the receiver expression and `$name`
# one argument; `...` is every other argument and the block, passed through
# unchanged. A pattern without parentheses matches only a call without
# arguments or a block, and keywords in a pattern must appear with that value.
# `manual: hint` marks a change that has no mechanical rewrite; the hint says
# what to write instead. A trailing `# note` states a further condition.
#
# Builtin type names are also lowercase only: `Int` and every other casing is
# rewritten to its lowercase spelling, as a rule rather than an entry here.

# Every call: one without arguments is written without parentheses.
*: $x.$name() => $x.$name  # a block, if any, stays
*: $name() => $name  # a block, if any, stays

# Every type.
T: $x.nil? => $x == nil
T: $x.eql?($y) => $x == $y
T: $x.equal?($y) => $x == $y
T: $x.itself => $x
T: $x.freeze => $x
T: $x.clone => $x.dup
T: $x.string => $x.to_s
T: $x.is_a?($type) => $x.is_type?(:$type)
T: $x.kind_of?($type) => $x.is_type?(:$type)
T: $x.instance_of?($type) => $x.is_type?(:$type)
T: $x.tap(...) => manual: use the receiver itself, running the block's statements before it
T: $x.yield_self(...) => manual: bind the receiver to a local and write the block's expression
T: $x.send(...) => manual: dispatch by name is removed; call the member, or use case over the name
T: $x.public_send(...) => manual: dispatch by name is removed; call the member, or use case over the name
T: $x.respond_to?(...) => manual: dispatch by name is removed; use case over the name or is_type?

# Strings.
string: $x.size => $x.length
string: $x.intern => $x.to_sym
string: $x.sub($pattern, ..., regex: true) => $x.sub(Regex.new($pattern), ...)
string: $x.sub(..., regex: false) => $x.sub(...)
string: $x.sub!($pattern, ..., regex: true) => $x.sub!(Regex.new($pattern), ...)
string: $x.sub!(..., regex: false) => $x.sub!(...)
string: $x.gsub($pattern, ..., regex: true) => $x.gsub(Regex.new($pattern), ...)
string: $x.gsub(..., regex: false) => $x.gsub(...)
string: $x.gsub!($pattern, ..., regex: true) => $x.gsub!(Regex.new($pattern), ...)
string: $x.gsub!(..., regex: false) => $x.gsub!(...)

array: $x.reduce($initial, $operation) => manual: pass a block, such as `reduce(0) { |acc, x| acc + x }`
